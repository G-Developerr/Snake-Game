# 🐍 3D Retro Snake Game

A classic Snake game with a 3D retro twist — play with arrow keys!

[Play Now](https://g-developerr.github.io/Snake-Game/)

## 🕹️ How to Play
- Use the **Arrow Keys** to move the snake
- Eat the food to grow longer and score points
- Avoid hitting the walls or yourself!

## ✨ Features
- 🎮 Classic Snake gameplay
- 🌀 3D retro visual style
- ⌨️ Arrow key controls
- 📈 Score tracking
- 📱 Responsive design

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
